# Data

This folder contains the dataset used for the Retail Supply Chain Sales & Profitability Analytics project.

## Source

**Retail Supply Chain Sales Dataset**

[Kaggle — Retail Supply Chain Sales Dataset](https://www.kaggle.com/datasets/shandeep777/retail-supply-chain-sales-dataset)

## Dataset Overview

The source workbook contains two main datasets:

### Retail Order Dataset

- **Rows:** 9,994
- **Columns:** 23

This table contains transactional retail order information covering customers, products, sales, profitability, discounts, returns, geography, shipping, and salespeople.

### Calendar Table

- **Rows:** 1,826
- **Columns:** 12

The calendar table provides date attributes used for time-based analysis and Power BI time-intelligence calculations.

# Data Dictionary

## Retail Order Dataset

| Column | Description |
|---|---|
| **Row ID** | Unique identifier for each transaction record |
| **Order ID** | Identifier of the customer order |
| **Order Date** | Date when the order was placed |
| **Ship Date** | Date when the order was shipped |
| **Ship Mode** | Shipping method used for the order |
| **Customer ID** | Unique identifier for the customer |
| **Customer Name** | Customer name |
| **Segment** | Customer segment |
| **Country** | Country associated with the order |
| **City** | City associated with the order |
| **State** | State associated with the order |
| **Postal Code** | Postal code associated with the order |
| **Region** | Geographic region |
| **Product ID** | Unique identifier for the product |
| **Category** | Product category |
| **Sub-Category** | Product sub-category |
| **Product Name** | Product name |
| **Sales** | Sales revenue generated by the transaction |
| **Quantity** | Quantity of products sold |
| **Discount** | Discount applied to the transaction |
| **Profit** | Profit generated by the transaction |
| **Returned** | Indicates whether the order/product was returned |
| **Retail Sales People** | Salesperson associated with the transaction |
